1) Данные должны передаваться с использованием протокола TLS 1.2+
2) Использовать протокол авторизации OAuth 2.0
3) Настроить логирование
4) Настроить аудит действий
5) Данные не должны хранится в нашем сервисе, сервис только проксирует данные до партнера через защищенный канал.
В ином случае будет необходимо поднять еще N сервисов для хранения данных (например, сервис который по ключу будет возвращает персональные данные, а наш сервис будет хранить только ключ)
6) Хранение персональных данных будет на стороне партнера, необходимо в договоре прописать соотвествие 152-ФЗ, а также провести аудит системы партнера.
7) Необходимо настроить мониотринг на аномальные действия
8) Для доступа к приложению также настрим 2FA
